If today is wet, does that change the probability that tomorrow is wet?

Independent versus dependent simulation

Suppose weather is either Dry or Wet.

An independent model might say

\[ Prob(\text{wet tomorrow}) = 0.3 \] no matter what happened today.

A dependent model might say

\[ Prob(\text{wet tomorrow given wet today}) \neq Prob(\text{wet tomorrow given dry today}) \]

The probability used for the next state depends on the current state.

The Markov idea

A Markov chain is a sequence of states

\[ X_0, X_1, X_2, \ldots \]

where the next state depends on the current state.

Examples:

  • today’s weather \(\rightarrow\) tomorrow’s weather
  • a customer’s current status \(\rightarrow\) next month’s status
  • an animal’s current habitat \(\rightarrow\) next habitat
  • a nucleotide \(\rightarrow\) a nucleotide later in evolutionary time

The Markov property

The defining assumption is

\[ P(X_{t+1} \mid X_t, X_{t-1}, \ldots, X_0) = P(X_{t+1} \mid X_t). \]

Once we know the present state, the earlier history gives no additional information about the next state.

Warning

Markov does not mean independent.

Usually \(X_{t+1}\) and \(X_t\) are strongly dependent.

A two-state weather model

Suppose

  • if today is Dry, tomorrow is Dry with probability \(0.85\)
  • if today is Dry, tomorrow is Wet with probability \(0.15\)
  • if today is Wet, tomorrow is Dry with probability \(0.40\)
  • if today is Wet, tomorrow is Wet with probability \(0.60\)

We can store all four probabilities together.

Transition matrix

  • Math
  • In R

\[ P = \begin{pmatrix} 0.85 & 0.15 \\ 0.40 & 0.60 \end{pmatrix} \]

states <- c("Dry", "Wet")

P_weather <- matrix(
  c(.85, .15,
    .40, .60),
  nrow = 2,
  byrow = TRUE,
  dimnames = list(from = states, to = states)
)

Rows describe the state now and columns describe the state next.

Dry 0.85 0.15
Wet 0.40 0.60

Simulate an entire Markov chain

simulate_chain <- function(P, initial, n_steps = 100) {
  states <- rownames(P)

  chain <- character(n_steps + 1)
  chain[1] <- initial

  for (t in seq_len(n_steps)) {
    chain[t + 1] <- sample(
      states,
      size = 1,
      prob = P[chain[t], ]
    )
  }

  chain
}

At every step:

  1. look at the current state,
  2. retrieve the corresponding row of \(P\),
  3. simulate the next state.

More than one step ahead

The transition matrix tells us what happens one step ahead.

What is the probability of going from Dry today to Wet two days from now?

There are two possible paths:

\[ \text{Dry}\rightarrow\text{Dry}\rightarrow\text{Wet} \]

or

\[ \text{Dry}\rightarrow\text{Wet}\rightarrow\text{Wet}. \]

So

\[ P(\text{Dry}\rightarrow\text{Wet in 2 steps}) = (.85)(.15)+(.15)(.60) = 0.2175. \]

Matrix multiplication does the bookkeeping

P_weather %*% P_weather
     to
from     Dry    Wet
  Dry 0.7825 0.2175
  Wet 0.5800 0.4200

The resulting matrix contains all two-step transition probabilities.

More generally,

\[ P^k \]

contains the \(k\)-step transition probabilities.

Warning

In R, P^2 squares each entry separately.

Use %*% for matrix multiplication.

Computing \(P^k\)

  • Manually
  • expm
matrix_power <- function(P, k) {
  out <- diag(nrow(P))

  for (i in seq_len(k)) {
    out <- out %*% P
  }

  dimnames(out) <- dimnames(P)
  out
}
library(expm)

Stationary distribution

A distribution \(\pi\) is stationary when

\[ \pi = \pi P. \]

Interpretation:

If the chain currently follows distribution \(\pi\), one more transition leaves the distribution unchanged.

We can find it computationally by repeatedly applying the transition matrix.

pi <- c(.5, .5)

for (i in 1:100) {
  pi <- as.numeric(pi %*% P_weather)
}

set_names(pi, states)
      Dry       Wet 
0.7272727 0.2727273

Simulation and the stationary distribution

For this chain, the long-run proportions from simulation should be close to the stationary probabilities.

sim_prop <- prop.table(table(long_chain))

tibble(
  state = states,
  stationary = pi,
  simulated = as.numeric(sim_prop)
)
# A tibble: 2 × 3
  state stationary simulated
  <chr>      <dbl>     <dbl>
1 Dry        0.727     0.734
2 Wet        0.273     0.266

Note

This connection between a Markov chain and its stationary distribution is the central idea behind Markov chain Monte Carlo (MCMC).

Continuous states

Markov models need not have discrete states

So far the state was one of two labels.

But the state could instead be a pair of continuous coordinates:

\[ X_t = \begin{pmatrix} x_t \\ y_t \end{pmatrix}. \]

For example, \(X_t\) could be the geographic position of an organism at time \(t\).

Brownian diffusion

A simple diffusion model says

Position at time \(t + \Delta t\) given position at time \(t\) is drawn from a multivariate normal distribution (mvtnorm::rmvnorm(x_t, mean = c(0, 0), Sigma)), centered on the position at time \(t\).

Equivalently, we can write

\[ X_{t+\Delta t} = X_t + \epsilon_t, \qquad \epsilon_t \sim N_2(0,\Sigma\Delta t). \]

The next location depends on the current location, but not on the entire path.

That is the Markov property again.

Simulating geographic diffusion

We will measure location relative to the starting point:

  • \(x\): kilometers east/west
  • \(y\): kilometers north/south
simulate_brownian <- function(n_steps = 100,
                              start = c(0, 0),
                              sigma = diag(2),
                              dt = 1) {

  locations <- matrix(
    NA,
    nrow = n_steps + 1,
    ncol = 2
  )

  locations[1, ] <- start

  for (t in 1:n_steps) {

    move <- rmvnorm(
      1,
      mean = c(0, 0),
      sigma = sigma * dt
    )

    locations[t + 1, ] <- locations[t, ] + move
  }

  tibble(
    step = 0:n_steps,
    east_km = locations[, 1],
    north_km = locations[, 2]
  )
}

What does \(\Sigma\) do?

For

\[ \Sigma = \begin{pmatrix} 1.2 & 0.45 \\ 0.45 & 0.7 \end{pmatrix}, \]

  • \(1.2\): east/west variance per unit time
  • \(0.7\): north/south variance per unit time
  • \(0.45\): correlation between east/west and north/south displacement

Note

For real geographic analyses over nontrivial distances, work in an appropriate projected coordinate system rather than directly adding normal noise to longitude and latitude.

Discrete time versus continuous time

Our weather chain changed at fixed steps:

\[ t=0,1,2,3,\ldots \]

But many processes evolve continuously.

For nucleotide evolution, a substitution can occur at any point in time.

This leads to a continuous-time Markov chain.

A biological example

DNA is written using four nucleotide states:

\[ \{A,C,G,T\}. \]

Suppose an ancestral sequence contains

A C G T T A C G A

After evolutionary time passes, a descendant might contain

A C A T T G C G A

We want a model for

\[ P(\text{descendant nucleotide}\mid \text{ancestral nucleotide},\text{time}). \]
